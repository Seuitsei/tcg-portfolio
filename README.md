# TCG Portfolio

Prototype mobile-first pour scanner et gérer une collection de cartes TCG.

## V1
- Pokémon
- prise de photo depuis smartphone
- saisie/confirmation manuelle de la carte
- portfolio stocké localement dans le navigateur
- prix d'achat

La reconnaissance automatique et les prix en temps réel seront ajoutés progressivement.
